# 模拟器阅读器（Sim Reader）

手机优先的暗夜风 **AI 文字模拟器客户端**：把完整玩法规则贴进来，按章节阅读、用选项或自定义行动推进——专为「长规则模拟器」设计，而不是普通聊天框。

正式体验：[https://ai-simulator-sooty.vercel.app/](https://ai-simulator-sooty.vercel.app/)

---

## 它解决什么问题

在聊天软件里直接跑模拟器，常见痛点是：

- 规则又长又碎，一滚动就找不到设定  
- 上下文一长，模型容易忘人设、忘规则  
- 剧情混在气泡里，想重看前面章节很痛苦  

本工具把体验改成 **阅读器 + 回合制**：规则常驻本局、正文按章展示、历史回合可回看，推进方式接近「点选项往下玩」。

---

## 核心能力

- **导入整份玩法**：粘贴 / 上传 Markdown 规则（如各类「xxx 模拟器」全文）  
- **按章节阅读**：小说式正文，而不是一串对话气泡  
- **选项 / 自定义推进**：点 A/B/C/D，或自己写行动发送  
- **历史回合回看**：左上「回合」可翻以前的章节，再回到最新继续  
- **更稳的开局**：能抽填写提纲的先填表；需要 AI 引导的（欢迎语 /「开始游戏」等）按规则走  
- **自带 API**：兼容 OpenAI 格式的接口；Key 只存在本机浏览器  
- **进度同步**：换手机 / 换浏览器时，用设定页导出 / 导入备份（不自动上云）

---

## 怎么开始玩

1. 打开设定页，填写你自己的 **Base URL / API Key / 模型**，保存  
2. **导入模拟器**：把完整规则 Markdown 贴进去（或选文件）  
3. 回大厅 → **新建对局** → 选模拟器；按页面提示填人设，或跟随 AI 开局  
4. 阅读正文 → 点底部「选项」或自定义行动 → 生成下一章  
5. 需要时用「回合」回看历史；换设备前务必到设定页做 **进度同步**

提示：生成章节时尽量保持页面在前台（少锁屏、少切应用）。手机可将站点「添加到主屏幕」，更像独立 App。

**注意：** 桌面快捷方式与普通浏览器有时是两套本地存档；删入口或清缓存前请先导出备份。

## 本地运行

需要 Node.js 18+。

```bash
cd ai-simulator
npm install
npm run dev
```

终端会打印 Local / Network 地址；手机需与电脑同一 Wi‑Fi 时，可用 Network 地址调试。

日常游玩更推荐直接用上面的 Vercel 链接，不必本机开服务。

---

## 部署到 Vercel

1. 将本仓库连接到 [Vercel](https://vercel.com)（Import GitHub 项目）  
2. 框架选 Vite，直接 Deploy  
3. `vercel.json` 已配置 SPA 路由  

推送到 `main` 后一般会自动重新部署。

---

## 电脑 ↔ 手机同步进度

进度存在浏览器 `localStorage`，两端不会自动相通。在 **设定 → 进度同步**：

1. 设备 A：导出全部进度 / 复制到剪贴板（可用微信发给自己）  
2. 设备 B：粘贴后点「合并导入」  

勾选「包含 API Key」可把密钥一并带走（只建议在自己的设备之间使用）。

---

## 技术说明（简要）

- 存档、模拟器包、API 设定均在本机 `localStorage`  
- 每回合请求大致携带：压缩后的规则 + 角色写入 + 近 2 回合全文 + 更早摘要  
- 模型需返回约定 JSON（应用内 system 提示已写明；正式剧情回合有字数等阅读器侧约束）  
- 纯前端静态站，用户自备大模型 API，服务端不代持 Key  

---

## 定位说明

这是一个 **通用模拟器阅读工具**：不内置具体玩法内容库。玩法规则由用户自行导入；生成剧情由用户配置的模型完成。
